## 一、技术选型对比

| 维度 | Plan 文档 | PRD 文档 | 当前实现 | 差距 |
|------|-----------|----------|----------|------|
| **框架** | SwiftUI | SwiftUI（隐含） | HTML/CSS/JS + FastAPI | ❌ 技术栈完全不同 |
| **3D 视口** | MTKView (Metal Kit) | Metal 实时渲染 | Canvas 2D 模拟动画 | ❌ 无真实3D渲染 |
| **架构** | TCA (The Composable Architecture) | 未指定 | FastAPI REST + WebSocket | ❌ 架构范式不同 |
| **通信** | UDS JSON-RPC | gRPC 流 → Swift → SwiftUI | HTTP REST + WebSocket | ⚠️ 通信方式不同但功能等价 |
| **图表** | Swift Charts | 未指定 | 无图表库 | ❌ 无数据可视化图表 |
| **平台** | macOS 原生 | macOS 原生 | Web 浏览器（跨平台） | ⚠️ 偏离但更灵活 |

### 分析

- Plan 文档明确**禁止 PyQt/Qt**（Section 5.2），要求走 SwiftUI
- PRD 文档要求「macOS 原生风格、适配浅色/深色模式自动切换」
- 当前 Web Dashboard 偏离了 macOS 原生要求，但提供了跨平台访问能力
- **建议**：V0.1 阶段 Web Dashboard 可作为过渡方案，V0.3 需按 PRD 迁移到 SwiftUI + Metal

- PRD 文档：V0.1 P0 必须有 GUI

当前实现选择了 PRD 的立场（做了 Web Dashboard），但 Metal 视口这一核心功能未能实现。

## 五、GUI 与底层架构对接对比

| PRD 要求 | 实现 | 状态 |
|----------|------|------|
| GUI操作 → gRPC请求 → Gateway → 仿真内核 | GUI → HTTP REST → SimulationServer.handle_request() | ⚠️ 走的是HTTP而非gRPC |
| 仿真状态/画面数据 → 内核推送 → GUI实时渲染 | WebSocket 广播事件 | ✅ 架构等价 |
| AI配置/Prompt → GUI提交 → 持久化 → 驱动Agent运行 | ⚠️ 仅提交，无持久化 | 部分实现 |
| 状态同步：gRPC流 → Swift → SwiftUI @Observable | WebSocket → JS | 架构等价 |

## 六、缺失功能汇总（按优先级排序）

### P0 — 核心缺失（影响基本可用性）

1. **3D 仿真视口**：当前是 Canvas 2D 模拟动画，无真实物理场景渲染
2. **场景资源树层级管理**：无法展开/折叠、无灯光/碰撞体节点
3. **实体属性编辑**：无法编辑位置/姿态/物理参数
4. **仿真录制与回放**：录制和回放完全缺失

### P1 — 重要缺失（影响完整体验）

5. **Agent 流程可视化画布**：协作链路图形化编辑
6. **运行日志区**：实时Agent决策/交互/报错日志
7. **右键上下文菜单**：新增/删除/复制/绑定传感器等
8. **拖拽添加物体**：场景编辑核心交互
9. **深浅模式自动切换**：PRD要求跟随系统
10. **打开 USD/URDF 场景文件**：场景导入功能
11. **最近项目记录**：持久化最近操作

### P2 — 优化项（锦上添花）

12. Swift Charts 数据可视化图表
13. 布局预设/字体缩放
14. 数据集导出实际功能（COCO/KITTI/JSON）
15. 框选批量操作
16. 实时画面投喂AI推理
17. Homebrew 状态检测
18. 官方文档入口链接

## 七、改进建议

### 短期（V0.1.x 补齐）

1. **接入 Three.js 替代 Canvas 2D**，提供 WebGL 3D 视口
2. **补齐右键菜单**：场景资源树右键操作
3. **补齐录制回放**：前端进度条 + 后端录制API
4. **深浅模式**：CSS 媒体查询 `prefers-color-scheme`
5. **Agent 日志面板**：WebSocket 推送 + 前端日志滚动区

### 中期（V0.2 对齐 PRD P1）

6. **Agent 流程画布**：集成流程图库
7. **场景资源树完整管理**：层级展开/折叠、灯光/碰撞体节点
8. **实体属性编辑器**：位置/姿态/物理参数实时编辑
9. **数据集导出**：对接 DatasetManager 真实导出
10. **环境一键检测增强**：Metal/protobuf/grpcio 细粒度检测

### 长期（V0.3 对齐 PRD）

11. **迁移到 SwiftUI + Metal**：按 Plan 文档要求做原生客户端
12. **UDS JSON-RPC 通信**：替换 HTTP REST
13. **TCA 架构**：状态管理重构
14. **USD 场景可视化编辑**：材质/灯光调整
15. **批量仿真任务管理**
